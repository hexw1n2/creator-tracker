# Creator Tracker rules

Before doing anything, read `AGENTS.md` in the project root. It explains the app and the rules.

The most important rules:
- This repository is public. Never add secrets, passwords, tokens, or personal emails.
- Never change or delete payment records (payouts, payout_items) or un-pay a video.
- Database and server changes are proposals: write them into a file and explain them. The owner applies them in Supabase.
- Make one small change at a time, test it with Live Server, and explain it in plain words.
- Ask before deleting or renaming files.
